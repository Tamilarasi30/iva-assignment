02 · Reference

Noise suppression

Smoothing filters trade detail for stability — each pixel is replaced by some summary of its neighborhood so that random sensor noise averages out.

FILTER / 01

Mean filter

out(x,y) = (1/n²) Σ neighborhood(x,y)

Replaces every pixel with the plain average of its k×k neighborhood. Cheap, separable, and effective against uniform (Gaussian-like) sensor noise — but it blurs edges indiscriminately since it has no idea an edge is there.

FILTER / 02

Median filter

out(x,y) = median( neighborhood(x,y) )

Sorts the neighborhood and keeps the middle value instead of averaging. Because outliers can't drag a median the way they drag a mean, this is the standard choice against salt-and-pepper (impulse) noise, and it preserves edges far better than linear smoothing.

FILTER / 03

Gaussian filter

G(x,y) = 1/(2πσ²) · e^(-(x²+y²)/2σ²)

Weights neighbors by a bell curve centered on the pixel, so nearby values matter more than distant ones. σ controls the spread: larger σ means stronger, wider smoothing. It's separable into two 1D passes and is the standard first step before gradient-based edge detection, including Canny.

03 · Reference

Gradient operators

Edges are where intensity changes fast. Gradient operators convolve the image with small kernels tuned to respond to that change, in one or both directions.

OPERATOR / 01

Sobel

|G| = √(Gx² + Gy²)

Pairs a directional difference with a smoothing weight (the 1-2-1 row/column), which makes it noticeably less noise-sensitive than Prewitt while staying a simple, fast, separable kernel. It's the most commonly used first-derivative edge operator in practice.

Laplacian

A second-derivative, direction-agnostic operator: it responds wherever the rate of intensity change itself is changing, so it fires on edges from every orientation at once with a single kernel. 04 · Reference

Canny edge detection

Canny doesn't introduce a new gradient — it wraps Gaussian smoothing and Sobel gradients in a five-step pipeline designed to produce thin, connected, well-localized edges.

01

Gaussian smoothing

The image is blurred first, because raw gradients amplify pixel-level noise. A larger σ removes more noise but also more fine detail — it's the same trade-off as the Gaussian filter above.

reuses: Gaussian filter
02

Gradient computation

Sobel kernels compute Gx and Gy at every pixel, giving both a gradient magnitude (edge strength) and a gradient direction (which way the intensity is changing fastest).

reuses: Sobel operator
03

Non-maximum suppression

Edges from step 2 are typically several pixels wide. At each point, the algorithm checks the two neighbors along the gradient direction and keeps the pixel only if it's a local maximum — thinning wide ridges down to single-pixel-wide lines.

04

Double thresholding

Every remaining pixel is classified against two thresholds: above the high threshold it's a strong edge, below the low threshold it's discarded, and in between it's marked as a weak edge — a candidate that needs more context.

05

Edge tracking by hysteresis

Weak edges survive only if they're connected — directly or through a chain of other weak edges — to a strong edge. Isolated weak responses, usually noise, are dropped. What's left is the final binary edge map.
