# IMG//PREP — Image Preprocessing Lab

An interactive **Digital Image Processing** web application for learning and experimenting with fundamental image preprocessing techniques.

## Features

* 🖼️ Upload and process images directly in the browser
* 🔊 Add noise to test images
* 📊 Mean, Median, and Gaussian filters
* 📐 Sobel, Prewitt, and Laplacian operators
* ✨ Canny Edge Detection
* 📚 Built-in explanations, formulas, and kernel matrices
* ⚡ Real-time client-side image processing
* 🔒 Images are processed locally and are not uploaded

demo link: https://preeminent-blini-b4b681.netlify.app

## 🧠 Topics Covered

### Noise Suppression

* Mean Filter
* Median Filter
* Gaussian Filter

### Gradient Operators

* Sobel Operator
* Prewitt Operator
* Laplacian Operator

### Canny Edge Detection

The application demonstrates the major stages of the Canny algorithm:
1. Gaussian Smoothing
2. Gradient Computation
3. Non-Maximum Suppression
4. Double Thresholding
5. Edge Tracking by Hysteresis

## 🛠️ Technologies Used
* HTML5
* CSS3
* JavaScript
* HTML Canvas API

## 📌 Project Purpose

This project provides a hands-on way to understand how image preprocessing techniques work by allowing users to apply different filters and edge detection algorithms to images and observe their results interactively.
All image processing happens **client-side in the browser**. Images are not uploaded to a server.
